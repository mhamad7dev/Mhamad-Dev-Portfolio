# Mhamad-Div Portfolio Website

### 📋 نبذة عن المشروع
موقع معرض أعمال شخصي مخصص لعرض المشاريع والخبرات. يسعى المشروع إلى دمج أمان البيانات وحماية خصوصية المستخدمين كجزء أساسي من تطويره المستمر في الـ Backend.

### 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية (Frontend):** HTML, CSS, JavaScript.
- **الخلفية (Backend حالياً):** Node.js, Express.js.

### 🚀 خطط التطوير المستقبلية
- **نظام مصادقة آمن:** قفل الموقع بحيث لا يمكن دخوله إلا بعد تسجيل الدخول.
- **تشفير البيانات:** تشفير كلمات السر وحماية معلومات المستخدمين بشكل كامل.
- ربط الموقع بقاعدة بيانات حقيقية.
- إضافة ميزات تفاعلية جديدة للمستخدمين.
- اضافة مسار للرسائل القادمة من المستخدمين وربطها للرد عليها.

- ### 💻 طريقة تشغيل السيرفر محلياً

1. تأكد من تثبيت Node.js.
2. من مجلد المشروع شغّل:
   ```bash
   cd server
   npm install
   npm start
   ```
3. افتح الموقع باستخدام Live Server أو Live Preview. واجهة الموقع قد تستخدم البورت 3000 أو 5500، أما API تسجيل الدخول فيعمل على البورت 3002.

- **مستودع السيرفر (Backend Repository):** [Secure-Portfolio](https://github.com/m73del/Secure-Portfolio.git)
